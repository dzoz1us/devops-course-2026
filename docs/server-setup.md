# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- **ОЗУ:** 2048 МБ
- **Количество ядер:** 2
- **Жёсткий диск:** 25 ГБ, динамически расширяемый

## 2. Сетевые интерфейсы
| Адаптер | Тип | Адрес | Назначение |
|---|---|---|---|
| 1 | NAT | 10.0.2.15 | Доступ в Интернет, проброс SSH-порта |
| 2 | Host-only | 192.168.56.103 | Доступ с хостовой системы, локальное имя |

## 3. Правило проброса портов
- **Порт хостовой системы:** 2222
- **Порт гостевой системы:** 2222 (изменён со стандартного 22)

## 4. Учётные записи
- `student`: входит в группу `sudo`, аутентификация по паролю. Используется для первоначальной настройки.
- `devops`: входит в группу `sudo`, аутентификация строго по SSH-ключу.

## 5. Служба SSH
- **Порт:** 2222
- **Файл конфигурации:** `/etc/ssh/sshd_config.d/99-hardening.conf`
- **Изменённые директивы:**
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `MaxAuthTries 3`
  - `AllowUsers devops`
  - `X11Forwarding no`

## 6. Правила межсетевого экрана (UFW)
- **Политики по умолчанию:** `deny incoming`, `allow outgoing`
- **Разрешающие правила:**
  - `80/tcp` (HTTP)
  - `443/tcp` (HTTPS)
  - `2222/tcp` (SSH с ограничением частоты подключений - LIMIT)

## 7. Снимки состояния
1. `01-clean-install` — сразу после установки ОС и обновления пакетов.
2. `02-keys-configured` — после создания пользователя `devops` и настройки входа по ключу.
3. `03-ssh-hardened` — после ужесточения конфигурации SSH и настройки UFW.

## 8. Веб-сервер
- Пакет: nginx
- Конфигурация: /etc/nginx/sites-available/devops-site
- Каталог ресурса: /var/www/devops-site (владелец devops:devops, права 755/644)
- Сертификат: /etc/ssl/certs/devops.crt (644)
- Ключ: /etc/ssl/private/devops.key (600, root:root)
- Команда формирования сертификата: openssl req -x509 ...

## 9. Контейнеризация
- Способ установки Docker Engine: официальный репозиторий Docker.
- Версия Docker: (впишите вывод `docker -v`).
- Участники группы docker: пользователь devops.
- Расположение проекта на сервере: /home/devops/app
- Расположение файла .env: /home/devops/app/.env (права 600).
- Публикуемые порты: 127.0.0.1:5000 (приложение).
- Именованные тома: app_db_data (для PostgreSQL).
- Конфигурация обратного прокси: Nginx проксирует /app/ на http://127.0.0.1:5000/.
